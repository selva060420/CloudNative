# Java Interview Preparation Guide

Comprehensive Java study guide tailored for **3+ years experienced Software Engineers** targeting roles in cloud-native, microservices, and distributed systems.

## Topics

| # | Topic | Focus Areas |
|---|-------|-------------|
| 01 | [Core Java](01-core-java/) | OOP, Generics, Records, Sealed Classes, Enums |
| 02 | [Collections](02-collections/) | HashMap internals, ConcurrentHashMap, equals/hashCode, Comparable vs Comparator |
| 03 | [Java 8+](03-java8-plus/) | Streams, Lambdas, Optional, Functional Interfaces |
| 04 | [Multithreading](04-multithreading/) | ExecutorService, CompletableFuture, Virtual Threads, Locks |
| 05 | [Exception Handling](05-exception-handling/) | Custom Exceptions, Best Practices |
| 06 | [Design Patterns](06-design-patterns/) | Singleton, Factory, Builder, Observer, Strategy |
| 07 | [Spring Boot](07-spring-boot/) | DI/IoC, Bean Lifecycle, Profiles, Auto-config, Actuator |
| 08 | [Microservices](08-microservices/) | Circuit Breaker, Saga, CQRS, API Gateway, Service Discovery |
| 09 | [REST API](09-rest-api/) | HTTP Methods, Versioning, OAuth2, JWT, Rate Limiting |
| 10 | [SQL & NoSQL](10-sql-nosql/) | Joins, Indexing, Cassandra Data Modeling |
| 11 | [Testing](11-testing/) | JUnit5, Mockito, Integration Testing, TDD |
| 12 | [System Design](12-system-design/) | Caching, Load Balancing, Message Queues, DB Sharding |
| 13 | [DSA](13-dsa/) | Arrays, Trees, Graphs, DP, LeetCode Patterns |

## How to Use

- Each folder has a `README.md` with theory, interview Q&A, and time complexity analysis
- Code examples are in `src/` subdirectories as runnable Java files
- Start with topics most relevant to your target role

## Profile Context

Based on: Java, Spring Boot, Microservices, AWS, Kubernetes, Docker, Cassandra, CI/CD, 5G/Telecom
